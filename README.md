# BrokenHack

**BrokenHack** is a free Geometry Dash hack / mod menu built with the Geode framework.

It provides a collection of useful gameplay, practice, visual, and utility features to enhance your Geometry Dash experience.

## Features (WIP)

- Press **TAB** to open the menu
- Category-based UI
- First category: **Broken Hack**

More categories and features coming soon.

## Installation

1. Install [Geode](https://geode-sdk.org)
2. Download the latest `.geode` release from this repository
3. Install it through the Geode in-game menu or drop it into the `geode/mods` folder

## Building

```bash
geode build
```

Requires Geode SDK and the Geode CLI.
